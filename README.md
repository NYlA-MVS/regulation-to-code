# Regulation-to-Code (working name: Rulecraft)

Idea #100 from the Idea Bank. Thai regulations arrive as announcements (ประกาศ) and PDFs. Rulecraft turns one regulation into versioned, tested code checks that a seller or SME runs against their own data. Every result cites the clause it came from.

> กฎหมายใหม่หนึ่งฉบับ ควรกลายเป็นชุดตรวจที่ SME กดรันได้ในวันเดียวกัน ไม่ใช่เอกสารที่ไม่มีใครอ่าน
> (One new regulation should become a check that an SME can run the same day, not a document nobody reads.)

- **Event:** Sea × OpenAI Regional Codex Hackathon Thailand, Sat 21 Nov 2026. Coding runs 10:00–17:00, at Shopee Thailand, Singha Complex 25F.
- **Applications close:** 23 Oct 2026, 11:59 PM, via https://luma.com/39zve8ph
- **Tracks:** AI-Native Products & Operations is the main fit. Deep Domain AI also fits if we go deep on one regulation.
- **Based on:** Pieces of Them (Univ. of Utah Codex Hackathon 2026, 1st), which used AI for regulatory compliance.

## Ground rule: no app code before the event

Thailand's rule: "All new development must take place during the event … Only work completed during the event will be judged." Before 21 Nov we only prepare:
- research and regulation texts
- test data
- designs
- the AGENTS.md draft
- the pitch

Git history for the app starts after 10:00 on the day, so the judged work is obvious.
